# Deuda técnica intencional

Este archivo documenta problemas deliberados para que DevGotchi pueda detectar un repositorio con mala salud.

- Cobertura insuficiente.
- Suite de pruebas mínima.
- Pipeline de CI deliberadamente roto.
- Mala higiene de configuración.
- Código no utilizado.
- Validaciones débiles.
- Dependencias no actualizadas de forma intencional.

Todos estos problemas son parte del laboratorio.
